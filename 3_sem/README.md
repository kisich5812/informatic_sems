# Семинар 3

Задания с 3 семинара. Исправленный исходный файл `5_sh_aska.c` и версия на большее количество чатов `5.c` находятся в поддиректории `5`.

При запуске чата требуется указать имя и номер комнаты в качестве аргументов командной строки. Номер комнаты требуется для инициализации shared memory.
Пользователи в одной комнате используют одну shared mem и слышат друг друга.
